How pricing is calculated

Estimates use Gemini-reported token usage and the OpenRouter reference rates stored with each paid request. Free requests are recorded at $0.00. Missing provider usage or unavailable pricing is shown as a pricing gap instead of being guessed.

These local estimates can differ from Google’s final bill and cannot include requests made by other applications.
